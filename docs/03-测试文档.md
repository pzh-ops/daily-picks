---

## 1. 测试策略

| 层级 | 范围 | 工具 | 目标 |
|---|---|---|---|
| 单元测试 | 单模块（config/storage/ranker/digest/feedback…） | pytest | 覆盖核心逻辑分支 |
| 集成测试 | 模块间协作（采集→入库→排序→推送），**所有 HTTP 用 respx mock** | pytest + respx + pytest-asyncio | 验证数据流正确性 |
| E2E | `cli.run_once` 全流程（mock 外部 HTTP） | pytest + respx | 一测到底，含降级路径 |
| 手动验收 | 真实外部调用（DeepSeek/微信 webhook） | 命令行 | 上线前最后一关（§7） |

- 覆盖率目标：核心模块（storage/ranker/llm/digest/publisher/feedback/sources）**≥85%**（`coverage report --fail-under 85`）。
- 外部依赖一律 mock：**测试过程不允许真实网络请求**（respx 默认拦截所有 httpx 请求，未匹配路由直接断言失败）。
- 时间相关用例用 `freezegun` 冻结。

### 1.1 运行命令

```bash
uv run pytest                          # 全量
uv run pytest -k "rank"               # 按模块
uv run pytest --cov --cov-report=term-missing   # 覆盖率
uv run ruff check .
```
