## 1. M10：用户画像与启动向导

### 1.1 `daily_picks/setup.py`

```python
DEFAULT_TAGS = ["AI大模型", "编程开发", "创业商业", "投资经济", "人文历史", "个人成长"]
TAG_SOURCE_MAP: dict[str, list[str]]  # 见设计文档 §6.1（内置映射）
```

实现细节：

- `run_setup(cfg, storage, llm)`：
  1. 调 `choose_tags` → tags
  2. 调 `recommend_sources(tags, llm)` → sources（源 key 列表）
  3. 调 `choose_top_n` → top_n
  4. `storage.save_profile(tags=json.dumps(tags), sources=json.dumps(sources), top_n=top_n)`（新方法，见 1.2）
  5. 更新 `cfg.profile`（tags/sources/top_n/enabled=True），写回 config.yaml（用现有配置读写函数，`daily_picks/config.py` 若无可写回函数则新增 `save_config(cfg, path)`）
  6. 打印结果摘要
- `choose_tags`：打印编号+标签，提示"输入序号（逗号分隔），或 `自定义:xxx` 追加，空回车 = 默认前 3 个"
- `recommend_sources`：取 `TAG_SOURCE_MAP` 并集；llm 非空时 `_llm_recommend` 补充新源（注册到 source_registry，key 用 `rss:<名称>`）
- `_llm_recommend`：prompt 要求 JSON `{"sources":[{"name":"机器之心","url":"https://www.jiqizhixin.com/rss"}]}`，每标签 ≤3 个；url 校验以 http(s):// 开头
- `choose_top_n`：`input()` 默认 5，int() 转换失败或越界（1-10）重输

### 1.2 `daily_picks/storage.py` 新增方法

```python
def save_profile(self, tags: list[str], sources: list[str], top_n: int) -> None:
    """INSERT OR REPLACE INTO user_profile (id=1, tags, sources, top_n, updated_at)"""

def load_profile(self) -> dict | None:
    """SELECT tags, sources, top_n FROM user_profile WHERE id=1；无行返回 None"""

def save_tag_weight(self, tag: str, weight: float, source: str = "manual") -> None:
    """UPSERT tag_weights，weight clamp [0.2, 2.0]"""

def list_tags(self) -> list[tuple[str, float]]:
    """SELECT tag, weight FROM tag_weights ORDER BY weight DESC"""

def register_source(self, key: str, name: str, url: str, tags: list[str]) -> None:
    """INSERT OR REPLACE INTO source_registry"""

def list_sources(self, enabled_only: bool = True) -> list[dict]:
    """SELECT key, name, kind, url, tags, enabled FROM source_registry"""
```

## 2. M11：深度选材与 v3 推送

### 2.1 `daily_picks/deep.py`

- `deep_analyze(article, llm, weights)`：
  - prompt system：`你是资深内容编辑，评估一篇文章的思考深度。` user：标题+摘要+URL + 用户兴趣（weights 转关键词清单）
  - JSON 输出：`{"deep_score": 0-100, "keywords": ["k1","k2","k3"], "reason": "≥2句，必须引用文章具体信息，禁止：深入浅出/受益匪浅/干货满满/值得一读/不容错过"}`
  - 校验：deep_score 非数字或越界 → ok=False；keywords 非数组或 <3 → 截断/回退；reason 空 → 回退"文章围绕 {title} 展开"
  - 返回 DeepResult(article_id=article.id 或 ScoredArticle.article_id, ...)
- `deep_filter(candidates, llm, threshold)`：
  - `asyncio.gather` 并发 ≤3（信号量）；单篇超时 30s（`asyncio.wait_for`）
  - 保留 deep_score ≥ threshold；ok=False 的**保留**（fail-open）
  - 过滤后 len < 5（profile.top_n）→ threshold -= 10 再跑一次（仅一次）
  - 返回 (filtered, deep_results 全量)
- `format_keywords`：顿号连接，max 5 个截断

### 3.2 `daily_picks/feedback.py`

- `parse_feedback(raw, llm)`：
  - prompt：system=`你是反馈分析师，解析用户对每日精选的反馈。` user=原文
  - JSON：`{"intent":"like|dislike|expand|adjust|none","article_id":null|int,"tags":[...],"keywords":[...],"top_n":null|int}`
  - 启发式兜底（无 LLM/key 失败）：含"不要/少推/反感" → dislike；含"多推/喜欢/想看" → like+expand；含"条" → adjust 提取数字；否则 none
- `apply_feedback(fb, storage, extract_keywords=True)`：
  - 落 feedback_text（channel='hermes'）
  - like/dislike + article_id：写 feedback 表（复用 v1 方法）；tag_weights：该文章命中标签 +0.1/-0.1
  - expand：每个新 tag `save_tag_weight(tag, 1.5, 'feedback')`；tags 写入 user_profile.tags（去重合并）
  - adjust：top_n 校验 1-10 后 `save_profile(..., top_n)`（保留原 tags/sources）
  - extract_keywords：keywords 写 interest_weights（UPSERT，weight=原值+0.1，clamp [0.2,2.0]）
- `evolve_weights(storage)`：M13，见 §4

## 5. Prompt 模板汇总（实现直接复用）

### 5.1 深度分析（deep_analyze）

```
system: 你是资深内容编辑，评估文章思考深度。评分标准：观点原创性(40%)、论证扎实度(30%)、
信息密度(20%)、对读者的启发价值(10%)。推荐理由必须引用文章的具体观点/数据/场景，
禁止使用任何套话。
user: 标题：{title}\n摘要：{summary}\nURL：{url}\n用户兴趣关键词：{keywords}
输出 JSON：{"deep_score": <0-100整数>, "keywords": [3-5个名词短语],
"reason": "2-3句，含具体引用，禁止'深入浅出/受益匪浅/干货满满/值得一读/不容错过'"}
```

### 5.2 反馈解析（parse_feedback）

```
system: 你是用户反馈分析师。意图定义：like=对内容满意；dislike=不满；expand=希望扩展某方向
（含新标签）；adjust=调整条数；none=无法归类。
user: 用户反馈：{raw}
输出 JSON：{"intent": "like|dislike|expand|adjust|none", "article_id": null,
"tags": [提取的新标签，intent=expand 时], "keywords": [从中提取的兴趣关键词],
"top_n": null}（top_n 仅 intent=adjust 时填数字）
```

### 5.3 来源推荐（_llm_recommend）

```
system: 你是内容源推荐专家。根据用户兴趣标签推荐高质量深度内容源（RSS）。
user: 标签：{tags}
输出 JSON：{"sources": [{"name": "源名", "url": "https://...rss 地址"}]}（每个标签最多 3 个）
```

## 6. 错误处理约定

- 所有新命令/函数不抛裸异常到 CLI 顶层（try/except → stderr 中文提示 + return 1）
- deep/feedback LLM 失败一律 fail-open（降级或记录不阻断）
- setup 中断（KeyboardInterrupt）→ 提示"向导未完成，可随时重跑 daily-picks setup"
