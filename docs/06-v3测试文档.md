## 8. 手动验收清单（每里程碑收尾跑一遍）

```bash
cd ~/daily-picks
uv run pytest -q                                   # 全绿
uv run pytest --cov=daily_picks --cov-report=term-missing | grep TOTAL
uv run ruff check daily_picks/ tests/
uv run daily-picks setup <<< $'1,2\n\n3\n'         # M10：管道输入走通向导（临时库防污染）
uv run daily-picks feedback "多推点AI硬件"          # M12：文字反馈落库
uv run daily-picks stats                           # 输出含 v3 计数
```

- 真实数据验证用备份库：`mv data/daily_picks.db data/daily_picks.db.bak` 后重建（幂等采集会 dedupe，旧库 dry-run 候选为空）
